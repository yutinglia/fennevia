# 本機擴充套件

目前原始碼已提供此功能；尚未發布新版安裝包。

在普通視窗開啟 **自訂 → 本機擴充套件**，選擇「加入檔案」或「加入資料夾」。
檢查名稱、版本、要求的存取權及可能稍後要求的選用權限，再按「加入並啟用」。
確認前不執行套件；取消會清理已暫存的副本。可用 Tab 操作，Escape 取消確認，
焦點返回原按鈕。關閉自訂面板或切換分頁也會取消未確認的選取。

支援 Firefox 相容的 WebExtension 資料夾、XPI、ZIP；`manifest.json` 必須直接
位於根目錄。套件須有作者提供的固定 Gecko ID。Chrome CRX、只有 Chrome API
的套件、沒有固定 ID 的套件及 `.uc.js` 不能直接使用。已簽章的套件可改從
頁面底部的 Firefox 擴充套件管理員走原生安裝。

第一版只接受 Windows 系統磁碟上的普通路徑，profile 也須符合此條件。
網路路徑、其他磁碟、junction／symlink、含歧義名稱的檔案會被拒絕。
每個套件最多 4,096 個項目、16 層、單檔 16 MiB、總計 128 MiB；
壓縮檔最多 64 MiB，manifest 最多 256 KiB。最多保存 24 個套件，
同時待確認副本也最多 24 個；registry 上限 512 KiB。

Fennevia 使用自己的副本。原下載檔移動或刪除不影響之後載入；編輯原檔也
不會更新已加入的版本。使用「從檔案更新／從資料夾更新」重新檢查並確認。
「重新載入」重新載入已保存的副本，可能再觸發套件的安裝事件。

「停用」及「全部停用」保留副本和登錄，不額外卸載。「啟用／重試」恢復項目。
「移除」會停止自動恢復並移除管理副本；原生卸載可能清除套件設定、UUID 和
權限，確認前會提示。原下載檔不會刪除。

啟用項目會在第一個普通視窗就緒後自動恢復，不必打開管理頁面。私人視窗
不能管理；Fennevia 不授予私人瀏覽權限。Safe start、Troubleshoot Mode、
套件停用或企業政策禁止安裝時不恢復。

這仍是 Firefox 的暫時安裝機制。已驗證測試套件的本機資料、固定身分及選用
權限跨重啟保留，但每次恢復會觸發 `runtime.onInstalled`，不觸發
`runtime.onStartup`。有些第三方套件因此可能重設設定或再次顯示歡迎頁；
也不能保證覆蓋瀏覽器啟動最早期的網路請求。

避免同時用其他工具安裝同一個套件。Fennevia 拒絕已知同 ID 衝突，偵測外部
替換後停止自動重試；Firefox 已開始的安裝仍可能取代同時安裝的同 ID 套件。
此限制經專案擁有者批准，並非「絕不覆蓋」保證。

## 中斷與恢復

- 顯示「上次載入未完成」時不會自動再試。先確認 Firefox 原生管理員的狀態，
  再明確按「啟用／重試」；更新失敗時仍保存舊副本，重試會使用舊版。
- 顯示衝突時，先在 Firefox／其他工具解決該安裝，再重試。Fennevia 不會
  自動移除另一個來源的套件。
- 副本缺失或變更時不執行它。可選取有效來源更新；若清理失敗顯示部分完成，
  先檢查目前版本，不把這當成完全取消。
- registry 無法安全讀取時，會保留資料並停止服務。先關閉 Firefox，備份
  profile 的 `fennevia/local-extensions`。必要時手動移走這個專用資料目錄，
  再啟動重新加入；不要修改 Firefox 的 `extensions.json` 或第三方 storage。
- 可在 `about:config` 將 `fennevia.localExtensions.enabled` 設為 false，
  阻止下次自動恢復。這個 preference 不會即時停用已載入的項目；即時停用
  請使用本管理器「全部停用」或 Firefox 原生管理員。

管理資料不包含原下載路徑，不納入 Fennevia 設定匯出或 Sync。套件程式碼只由
Firefox WebExtension runtime 執行；本功能不提供更新下載器，也不代替你判斷
作者是否可信。Firefox 自身的錯誤訊息可能包含套件來源，分享前請先遮蔽。

測試範圍與未執行項目見[實作驗證](research/firefox-159-local-extension-implementation.md)。
